Perspective Plot

# Persp
x <- seq(-10, 10, length= 30)
y <- x
f <- function(x,y) { r <- sqrt(x^2+y^2); 10 * sin(r)/r }
z <- outer(x, y, f)
z[is.na(z)] <- 1
# 0.5 to include z axis label
par(mar=c(0, 0.5, 0, 0), lwd=0.5)
persp(x, y, z, theta = 30, phi = 30, 
      expand = 0.5)
par(mar=c(5.1, 4.1, 4.1, 2.1), lwd=1)


# Compute the average height of each facet (small grid square)
nrz <- nrow(z)
ncz <- ncol(z)
zfacet <- (z[-1, -1] + z[-1, -ncz] + z[-nrz, -1] + z[-nrz, -ncz]) / 4

# Build a color gradient and map facet heights onto it
color <- colorRampPalette(c("darkblue", "skyblue", "white"))(100)
facetcol <- cut(zfacet, 100)

par(mar=c(0, 0.5, 0, 0), lwd=0.5)
persp(x, y, z, theta = 30, phi = 30, 
      expand = 0.5, col = color[facetcol])
par(mar=c(5.1, 4.1, 4.1, 2.1), lwd=1)

# Which countries dropped out compared to earlier full-coverage years?
setdiff(hpi$Country[hpi$Year == 2019], hpi$Country[hpi$Year == 2025])
[1] "Russia"              "Ukraine"             "Palestine, State of"
[4] "Israel"
  • I chose 2025, the most recent year available, since it best reflects current conditions. Coverage is reduced from earlier years. Russia, Ukraine, Palestine, and Israel all dropped out between 2019 and 2025, plausibly due to disrupted data collection amid conflict. Several columns have partial missing data in 2025 (HPI and HPI rank are missing for 19 countries; Ecological Footprint for 6). Notably, the raw GDP per capita column is entirely empty for 2025. I use the “GDP per capita (cleaned)” column instead, which the source workbook backfills with 2024 values, since true 2025 GDP figures were not yet available at time of publication.
